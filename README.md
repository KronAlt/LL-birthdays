# LL-birthdays
Use birthdays.py along with calendar.json and groups.json to create a static HTML file with a list of birthdays of characters and seiyuus from Love Live!. Images are stored locally in images/groups, images/seiyuus and images/characters; the JSON files reference these local copies.

Usage:
```
python birthdays.py
```

index.html is a page that uses javascript to populate the UI from the JSON files.
